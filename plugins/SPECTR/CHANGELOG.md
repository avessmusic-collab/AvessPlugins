# SPECTR Changelog

## 1.0.0 — 2026-11-03

Rebrand release: PRISM is now **SPECTR**. Pre-release versioning policy: stays 1.0.0 until public release.

### Breaking Changes
- Full rename PRISM → SPECTR: new plugin identity (PLUGIN_CODE `Prsm` → `Sptr`, product/bundle/target names, WebView bridge event names `prism*` → `spectr*`, state property namespace comments). DAW projects that referenced PRISM will show a missing plugin; PRISM 1.0.0 binaries were uninstalled.

### Migration Notes
- No automatic migration (pre-release, no external users). Re-insert SPECTR and re-apply settings in any old test session.
- Rollback: `backups/PRISM/v1.0.0/` holds the complete pre-rename source.

### Added
- **CH1/CH2 master source switch**: two chips in the nameplate pane switch the sidebar readout column (Loudness, True Peak, Stereo cells), **the needle meter, and every pane** (waveform, spectrogram, vectorscope, scope) to one source together (2026-11-09; per-pane chips still override a single pane afterwards). Exclusive toggle, CH1 default, chips tinted per source and following renames. Persisted as UI state `ui_readout_source` (page key `readout_source`), sanitized to {0,1}; pane follow happens on click only, so restored sessions keep their per-pane selections.
- **Per-source loudness**: each source's LoudnessMeter (already always-on) is now published in the snapshot (`SourceSnapshot.momentary/shortTerm/integratedLufs, loudnessRange`) and sent to the page as `meters.louds[]`. Global snapshot fields remain = source 0 for existing consumers/tests.
- **Waveform zoom double-click reset**: double-click on the waveform lane resets the span to the default 8 bars (wheel zoom 0.5–32 bars and SPAN presets unchanged).
- **Hover info (2026-11-04)**: custom tooltip layer across the whole UI — styled dark-glass tooltip (monospace, theme-aware, stage-scaled, z-index above popovers) that appears ~450 ms after the cursor rests and hides on move/click/wheel. Essentials-only texts (one short line per control; no gesture instructions except the waveform lane's wheel-zoom/double-click, which is otherwise undiscoverable). Covers readout cells (LUFS/TP/Stereo term glossary), needle meter, knobs, sidebar buttons, CH selectors on every pane, legend/footer chips, solo tags, SPAN/FLOW/GRID, waveform lane, status flag, and fullscreen button. Existing native `title` attributes are migrated to `data-tip` at boot so there are no double tooltips.

### Changed
- **Default color theme → Cyan/Violet** (blue/purple identity): APVTS `color_theme` default index 0 → 1, page boot state, `:root` CSS tokens, initial band-legend dots, footer chip color names, THEME button label. Saved sessions keep their stored theme; the 7-theme set is unchanged.
- Readout cells show the selected source only (big values tinted in the source color); True Peak cell now shows TP + SP of the selected source with a "max since reset" note.

### Fixed
- **True fullscreen blocked by a gray window in DAWs** (found in first Ableton test, 2026-11-04): DAW plugin editor windows float always-on-top, so the vacated (gray) editor window sat above the borderless kiosk window. Root cause: the kiosk was created at normal window level. Fix: `setAlwaysOnTop(true)` on the kiosk window so it covers the DAW's floating editor; the vacated editor now also paints a "SPECTR is in true fullscreen — press Esc or F to return" hint instead of an empty gray surface (visible on multi-display setups). Standalone never showed this because its window is not always-on-top.

### Fixed (code review, 2026-11-09)
- **Waveform freeze after host suspend**: an empty waveform batch (frames resuming before new columns exist) took the index-less append path and cleared `wfSynthTail`, cancelling the re-base against trailing synthetic idle columns — real columns were then skipped as "already have" and the strip froze for up to ~3 s. Empty batches now return without touching the re-base state.
- **Pooled snapshot honesty**: the four new per-source loudness fields are now reset to NaN in `resetSourceScalars`, restoring the "every member assigned on every build" invariant for recycled snapshot buffers.
- **Stereo metrics across ring-overrun gaps**: the gap branch now also resets StereoMetrics, so correlation/width/balance never blend audio across a stream discontinuity (loudness/true-peak/waveform already did this).
- **Waveform column peak scanned once**: `finishColumn()` computed the column's mono peak twice (onset test + next-column reference); hoisted to a single scan.
- **Stale PRISM artifacts removed from dist/**: the old PRISM.pkg / Windows exe / readme no longer ship with the rebrand; SPECTR installers are regenerated by packaging.
