## Context to Preserve

**Key decisions (Stage 0):**
- **Oversampling scope (AD-10):** the OS region wraps the whole voice + master chain (all oscillators/noise, `bodyHarmonics`, `tailDrive`, tone, transient, master morph, stereo, mix, gain, `tanh` limiter). Only DC blocker + analyzer taps at base rate. `processSamplesUp` fed a zero block. All in-region coefficients use `fsOversampled`, recomputed on factor change (audio thread, during the fade). CPU scales ~linearly with factor; `8×` = "high CPU"; Stage-17 escape hatch = base-rate render of pure-sine layers.
- Oversampling default `2x` provisional (confirm Stage 17); one `dsp::Oversampling` (`numChannels=2`) pre-built per factor, atomic swap + 64-sample fade, `useIntegerLatency = true`.
- Safety limiter = soft-clip `tanh` ceiling −0.5 dBFS, inside the OS region, adds 0 latency; no lookahead limiter in v1.
- Distortion morph order (parameter-spec authoritative): `tanh→cubic→asymmetric→soft-clip→hard-clip→foldback→bitcrush`; equal-gain crossfade; adaptive RMS makeup (static LUT fallback).
- Tone fixed pre-distortion. Mono crossover fixed 130 Hz. Pitch env single `pitchCurve`-driven normalised-exp; ratio/log domain; phase-continuous.
- `fundamental` in MIDI Pitch mode = global semitone offset relative to 55 Hz default.
- `mix` = equal-power processed↔silence (no dry path for instrument).
- `bodyAttack` fixed 2 ms internal (not a parameter).
- Native JUCE UI (custom LookAndFeel + Knob/WaveformDisplay/SpectrumDisplay/EnvelopeDisplay/PresetBrowser); analyzer via AbstractFifo + double buffer + 30 fps Timer FFT (message thread only).
