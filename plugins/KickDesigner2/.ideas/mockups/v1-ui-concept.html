UI Concept — v1

A blacked-out rack instrument for hard-techno kick design. It borrows the anatomy of the reference — a full-width screen up top, a row of rounded panels each pairing a big knob with an inset LCD readout and a cluster of small knobs, discreet power/solo dots — but it is darker, harder-edged, and organised for a 45-parameter synth rather than a 4-panel bass tool.

Palette

#08090E void #4B3C46 surface tint #452CDD primary #C041DD secondary #D1363A energy #1B139D depth #17155D depth #9EA0AE text

Violet→magenta is the signature; red is reserved for energy — Punch, drive, the transient of the waveform, the limiter LED. Blue-violet (#6f7bff, a lifted #452CDD) marks the pitch/sub/tail family so the eye can group the low-end controls.

Type

  • Chakra Petch — wordmark, panel titles, macro caps. Angular, technical, a little aggressive.
  • IBM Plex Sans — control labels, buttons.
  • IBM Plex Mono — every numeric readout and LCD, tabular figures.

Taken from the reference

  • Full-width screen; panel = title + dots + big knob + LCD + small knobs.
  • Glowing LCD readouts with label / value / unit.
  • Soft rounded rack body, inset wells, a single rim-light on the top edge.
  • A morph/selector LCD (their TUBE → our Character morph).

Deliberately different

  • Near-black ground, violet + red instead of blue + amber.
  • Kick oscilloscope up top — the most recent kick, red transient collapsing into a violet decaying sine — not a spectrum/EQ. WAVE / SPECTRUM toggles it.
  • A dedicated macro bar (Punch / Body / Crush / Tail) as the primary layer.
  • Two rows of eight panels for the full engine; a utility strip for transient, stereo, tuning, output + oversampling.
  • No input fader — it is an instrument, output-only.

Every control has a home

  • Header — preset shuttle, Save, Undo/Redo, Randomize, Mutate, A/B.
  • Scope — waveform of the last kick (spectrum on toggle); ms axis, dB scale.
  • Macros — Punch, Body, Crush, Tail.
  • Pitch — Fundamental, Start, Time, Curve  ·  Body — Level, Decay, Harmonics
  • Click — Level, Tone, Time, Pitch  ·  Sub — Level, Frequency, Decay
  • Tail — Level, Length, Tone, Drive  ·  Noise — Level, Decay, Tone, Type
  • Drive — Drive, Character (morph), Mix  ·  Tone — Low, Mid, High
  • Utility — Transient Attack/Sustain, Stereo Body/Click/Output width, Tune Mode + Tune/Fine, Output + Limiter + Mix + Oversampling.

45 automatable parameters + 4 macros, all visible without a menu. This mockup is a static concept — knob positions show a plausible “Warehouse” patch. Built for the native-JUCE UI in Stage 3.
