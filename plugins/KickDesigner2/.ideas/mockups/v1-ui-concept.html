UI Concept — v2

A soft-bodied rack instrument. The chassis, bezel, panel material and control anatomy follow the reference — a pillowy rounded body, a full-width inset screen, modules that pair a big soft knob with a glowing LCD and a cluster of small knobs, discreet round indicator lamps. Reworked for a 45-parameter kick synth: the four macros (Punch / Body / Crush / Tail) are the hero modules, and an eight-cell engine strip below carries every remaining section.

Palette

#08090E void #4B3C46 chassis warmth #452CDD primary #6F7BFF low-end family #C041DD LCD / Crush #D1363A energy #1B139D depth #9EA0AE text

Violet→magenta is the signature; red is reserved for energy — Punch, drive, the transient of the waveform, the limiter lamp. A lifted blue-violet (#6F7BFF) tags the low-frequency family (Pitch, Body, Sub, Tail) so those controls read as a group.

Type

  • Chakra Petch — wordmark, titles. Angular, technical.
  • IBM Plex Sans — labels, buttons.
  • IBM Plex Mono — every readout, tabular figures.

From the reference

  • Soft rounded chassis, thick bezel, rim-light on the top edge.
  • Panel = title + indicator lamps + big knob + inset LCD + small knobs.
  • Thin short knob pointer near the rim, not a full needle.
  • Glowing LCDs; a selector screen (their TUBE → our Character morph).

Deliberately different

  • Near-black ground, violet + red instead of blue + amber.
  • The screen is a kick oscilloscope — the most recent hit, computed from the pitch + amplitude envelopes: hot transient, then the fundamental settling and decaying. WAVE / SPECTRUM toggles it.
  • Macros are the hero row; an 8-cell engine strip fits the full parameter set with no menu.
  • Output-only — it is an instrument, no input fader.

Every control has a home

  • Header — preset shuttle, Save, Undo/Redo, Randomize, Mutate, A/B.
  • Punch — macro + Transient Atk/Sus + Pitch Start  ·  Body — macro/Fundamental + Level/Decay/Harmonics
  • Crush — macro + Drive/Character morph/Mix  ·  Tail — macro/Length + Level/Tone/Drive
  • Engine strip — Pitch (Fund/Start/Time/Curve), Click (Level/Tone/Time/Pitch), Sub (Level/Freq/Decay), Noise (Type/Level/Decay/Tone), Tone (Low/Mid/High), Stereo (Body/Click/Out width), Tuning (Mode/Tune/Fine), Output (Gain/Mix/Limiter/Oversampling).

45 automatable parameters + 4 macros, all on one face. Static concept — knob positions show a plausible “Warehouse” patch. Target: the native-JUCE UI in Stage 3.
