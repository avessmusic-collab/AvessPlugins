## Phase 3.2 Notes

- Chain order (binding): input trim -> filter -> tremolo -> saturation -> width, inside the engagement routing. At e == 0 the chain is skipped per 32-sample chunk (module states cleared once per rest period, LFOs keep running), so t = 0 stays bit-exact.
- Chain runs per control chunk on the absolute 32-sample grid; filter coefficients change only in controlTick; sat/width/tremolo smoothers advance per sample => block-size invariant (T11 checks it with the real modules).
- Non-finite dry samples are scrubbed on entry to the series chain (dry bus untouched); resetFeedbackModules() clears filter/saturator/crossover states and re-snaps module smoothers.
- lfoA (Sine) drives tremolo gain [1-depth, 1] and filter cutoff (octaves, applied after the 50 ms base smoothing); lfoB (Sine, +90 deg, rate x0.75) drives width sway + M/S rotation. Per-destination shapes (amp triangle / filter sine; Aggressive S&H) need a second shape per instance - deferred to Phase 3.4. Transport-start alignment uses the last-ticked cycles/beat.
- Soft-snap law: x' = x - 0.6*sin(2*pi*x)/(2*pi) in log2(cycles/beat): monotone, exact at ladder rungs, slope 0.4 at rungs.
- SaturationEngine makeup is the exact Gaussian level-compensation table at the -18 dBFS reference (not 1/sqrt(drive)). The asserted alias test runs at -18 dBFS peak (first-order ADAA cannot give 40 dB for full-scale-saturating levels at 48 kHz; hot-level figures are printed, not asserted). Fallback if it fails: 2x oversampling + dry delay compensation.
- Test hooks: setStubProcGainForTesting(g != 1) and setSeriesChainEnabledForTesting(false) bypass the real modules (used by the Phase 3.1 bus-algebra / telemetry tests).

## Phase 3.1 Notes

- Bit-exact t = 0 is a routing property: wet = dry + e*(proc - dry) with e == 0 short-circuited to dry; mix stage returns dry when wet == dry; knee skipped when s == 0; trim skipped when gain == 1.
- Control ticks fire on an absolute 32-sample grid (not per host block) => block-size invariant.
- `TensionEngine::setStubProcGainForTesting()` is a test-only hook (scales identity proc) so e / MIX algebra is observable.
- Fast path: `isAtRest()` skips the (stub) series chain; tails-quiet check is a placeholder until Phase 3.3.
- Runaway guard is skeleton only (OutputSafety::getFeedbackClamp(), not consumed yet).
- Test harness has a global operator-new allocation guard (armed around process()).
