## Context to Preserve

**Key Decisions:**
- Plugin type: Audio Effect (Transition Chain)
- Core concept: Fixed serial chain (Delay → Shimmer Reverb → Saturation → Filter), always running at full intensity; Filter (mix) knob crossfades dry/wet AND sweeps filter cutoff 800Hz→15kHz; Tail (duration) knob jointly scales delay time (tempo-synced) and reverb decay/size
- Saturation capped hard at +1dB, always active, not scaled by Mix
- Filter is clean/transparent lowpass, no resonance
- v2 UI direction: light skeuomorphic hardware (pale silver panels, black outer frame, brushed-metal knobs, cool blue-lavender glow, inset LCD readouts) - explicit visual pivot away from v1's dark neon-gradient identity
