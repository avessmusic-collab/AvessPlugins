## Context to Preserve

**Key Decisions (Stage 0, in addition to prior ideation decisions in mockup
history below):**
- Reverb freeze/hold implemented via `juce::dsp::Reverb::Parameters::freezeMode`
  (built-in), ramped via smoothstep across throw 90%-100%, NOT a custom FDN
  reverb (custom FDN retained only as documented fallback)
- Bipolar DJ Filter implemented via TWO always-running `juce::dsp::LadderFilter`
  instances (LPF24 pinned, HPF24 pinned) with a dead-zone (|sweep|<1%) +
  smoothstep crossfade (1%-5%) between a true dry-bypass tap and whichever
  filter matches sweep's sign - avoids any runtime `setMode()` switching and
  its associated click risk
- Dry/wet mix (throw) uses an equal-power (sin/cos) crossfade, not linear,
  because throw simultaneously increases wet-path density/loudness through
  several other mechanisms
- Output Glue and Stereo Width are both fixed internal constants (not
  parameters) - soft-clip drive 1.15, limiter -1.0dB/50ms release, M/S side
  gain 1.35x - preserving the locked 3-parameter contract
- Reverb Modulation (LFO-modulated micro-delay, ~0.15Hz/+-3ms) is the single
  most explicitly "okay to drop" component if it proves hard to tune -
  documented fallback: juce::dsp::Chorus, then no modulation at all
- Tempo sync for `space` uses a 10-step division table (1/32 through whole
  note) with `SmoothedValue`-ramped delay-time changes (~50ms) to avoid
  clicks on division changes; falls back to 120 BPM if host reports no tempo
- 0 samples reported latency - no component in this architecture requires PDC

**Prior decisions carried from Ideation (unchanged):**
- Signal chain (fixed order): Delay -> Reverb -> Bipolar DJ Filter -> Output
  Glue (soft-clip/limiter) -> Width (M/S, wet-only)
- THROW: triple-role macro (dry/wet, delay feedback, reverb decay/size), gates
  reverb freeze/hold near top of range, lightly scales feedback-loop saturation
- SPACE: links tempo-synced delay division + reverb size into one macro,
