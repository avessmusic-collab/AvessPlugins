## Context to Preserve

**Key Decisions:**
- Plugin type: Audio Effect (Transition/Tail Effect)
- Signal chain (fixed order): Delay -> Reverb -> Bipolar DJ Filter -> Output Glue
  (soft-clip/limiter) -> Width (M/S, wet-only)
- THROW: triple-role macro (dry/wet, delay feedback, reverb decay/size), gates
  reverb freeze/hold near top of range, lightly scales feedback-loop saturation
- SPACE: links tempo-synced delay division + reverb size into one macro,
  independent of THROW
- SWEEP: bipolar ladder filter - center=open, CCW=24dB lowpass closing,
  CW=24dB highpass opening, resonance rises toward both extremes
- Delay feedback loop is hand-built (not JUCE's built-in feedback delay) so a
  tanh waveshaper + FirstOrderTPTFilter one-pole lowpass can sit inside the loop
- v3/v4 UI direction: light skeuomorphic hardware (white/off-white frame, pale
  cool-silver panels, brushed-metal knobs, cool blue-lavender glow, inset LCD
  readouts) - this visual style is considered LOCKED; only knob count/labels/
  bindings should change in future iterations unless explicitly told to restyle
- Parameter IDs are LOCKED per `parameter-spec.md`: `throw`, `space`, `sweep`
  (all WebSliderRelay-bound; `sweep` is bipolar -100..+100, default 0.0)
