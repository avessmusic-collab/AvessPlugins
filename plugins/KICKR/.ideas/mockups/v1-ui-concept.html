UI Concept — v3

A soft-bodied rack instrument. The chassis, bezel, panel material and control anatomy follow the reference — a pillowy rounded body, a full-width inset screen, modules that pair a big soft knob with a glowing LCD and a cluster of small knobs, discreet round indicator lamps. Reworked for a 59-parameter kick instrument: a SAMPLE strip (the user's own recorded-kick bank + tweak controls), four macros (Punch / Body / Crush / Tail) as hero modules, and an eight-cell engine strip carrying every remaining synth section.

Palette

#08090E void #31353F chassis (ref grey) #452CDD primary #6F7BFF low-end family #C041DD LCD / Crush #D1363A energy #1B139D depth #9EA0AE text

The chassis grey is sampled from the reference (#31353F, cool slate). Violet→magenta is the signature; red is reserved for energy — Punch, drive, the transient of the waveform, the limiter lamp. A lifted blue-violet (#6F7BFF) tags the low-frequency family (Pitch, Body, Sub, Tail) so those controls read as a group.

Type

  • Chakra Petch — wordmark, titles. Angular, technical.
  • IBM Plex Sans — labels, buttons.
  • IBM Plex Mono — every readout, tabular figures.

From the reference

  • Soft rounded chassis, thick bezel, rim-light on the top edge.
  • Panel = title + indicator lamps + big knob + inset LCD + small knobs.
  • Thin short knob pointer near the rim, not a full needle.
  • Glowing LCDs; a selector screen (their TUBE → our Character morph).

Deliberately different

  • Near-black ground, violet + red instead of blue + amber.
  • The screen is a kick oscilloscope — the most recent hit, computed from the pitch + amplitude envelopes: hot transient, then the fundamental settling and decaying. WAVE / SPECTRUM toggles it.
  • SAMPLE strip (v2) — the user's own recorded-kick bank. Drop an audio file anywhere on the plugin → it’s copied into a managed folder and browsable here. A dashed slot shows the sample with its trim window; SYNTH / SAMPLE toggles blend or isolate the two engines. Twelve tweak controls: Level, Start/End, Reverse, Tune/Fine, MIDI-track, Attack/Decay, HP/LP, Crush. No factory samples ship.
  • Macros are the hero row; an 8-cell engine strip fits the full synth parameter set with no menu.
  • Output-only — it is an instrument, no input fader.

Every control has a home

  • Header — preset shuttle, Save, Undo/Redo, Randomize, Mutate, A/B.
  • Sample strip — Synth/Sample toggles, bank browser + drop slot, then Level/Start/End/Reverse/Tune/Fine/MIDI-track/Attack/Decay/HP/LP/Crush.
  • Punch — macro + Transient Atk/Sus + Pitch Start  ·  Body — macro/Fundamental (note) + Level/Decay/Harmonics
  • Crush — macro + Drive/Character morph/Mix  ·  Tail — macro/Length + Level/Tone/Drive
  • Engine strip — Pitch (Note/Start/Time/Curve — Fundamental is dialled as a musical note, e.g. A1, not raw Hz), Click (Level/Tone/Time/Pitch), Sub (Level/Freq/Decay), Noise (Type/Level/Decay/Tone), Tone (Low/Mid/High), Stereo (Body/Click/Out width), Tuning (Mode/Tune/Fine), Output (Gain/Mix/Limiter/Oversampling).

59 automatable parameters + 4 macros, all on one face; sample selection is a bank pick, not a parameter. Static concept — knob positions show a plausible “Warehouse” patch. Target: the native-JUCE UI in Stage 3.
