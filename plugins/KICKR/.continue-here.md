    `character = k/6` exactly, `t = 0` → pure `curve[k]` (curve 6 reached at `character = 1`,
    seg 5 / t 1).
  - **Adaptive RMS makeup (Open Q3 / AD-5):** one-pole mean-square meters
    `msIn += (1/480)·(u·u − msIn)` on the **driven input `u`** (pre-shaper), `msOut` on
    `yShaped`; `target = clamp(sqrt(msIn / max(msOut, 1e-9)), 0.25, 4.0)`;
    `makeup += mk_a·(target − makeup)` with `mk_a` for ~30 ms. **Primed** from a static
    `kCurveMakeup[7]` table (`{1.0, 1.1, 1.2, 1.12, 1.25, 1.3, 1.15}`) interpolated at
    `character` on the first `setParams` after `reset()`, and held **frozen for one RMS
    window (480 samples)** so block 1 is exact and deterministic (also makes the per-curve
    unit test exact). `msIn`/`msOut`/`makeup` + the S&H hold state denormal-flushed each
    sample; output `sanitize`d.
  - **`driveMix` blend:** `out = xClean + driveMix·(makeup·yShaped − xClean)` where `xClean`
    is the **PRE-drive-gain** input `x` → `driveMix = 0.0f` returns `x` exactly (verified
    bit-exact over a full noise sweep).

    existing base-rate `dcBlockers` after `processSamplesDown` handle it.

## Context to Preserve

**Key decisions (Stage 0):**
- **Oversampling scope (AD-10):** OS region wraps the whole voice + master chain through the `tanh` safety limiter. Only DC blocker + analyzer taps at base rate. `processSamplesUp` fed a zero block. All in-region coefficients use `fsOversampled`, recomputed on factor change. `8×` = "high CPU"; Stage-17 base-rate escape hatch for pure-sine layers.
- Oversampling default `2x` provisional (index 1); 4 `dsp::Oversampling` (`numChannels=2`) pre-built per factor, atomic swap + 64-sample fade, `useIntegerLatency = true`.
- Safety limiter = soft-clip `tanh` ceiling −0.5 dBFS, in-region, 0 latency; no lookahead limiter in v1.
- Distortion morph order (parameter-spec authoritative): `tanh→cubic→asymmetric→soft-clip→hard-clip→foldback→bitcrush`; equal-gain crossfade; adaptive RMS makeup (static LUT fallback).
- Tone fixed pre-distortion. Mono crossover fixed 130 Hz. Pitch env single `pitchCurve`-driven normalised-exp (`k = 0.6 + pitchCurve·8.4`); ratio/log domain; phase-continuous.
- `fundamental` in MIDI Pitch mode = global semitone offset `12·log2(fundamental/55)`.
- `mix` = equal-power processed↔silence (no dry path for instrument).
- `bodyAttack` fixed 2 ms internal (NOT a parameter).
- `output` 0 dB in −24..+12 → normalised ≈ 0.6667 (future Knob double-click-reset target).
- Native JUCE UI (custom LookAndFeel + Knob/WaveformDisplay/SpectrumDisplay/EnvelopeDisplay/PresetBrowser/**SampleBrowser**); analyzer via AbstractFifo + double buffer + 30 fps Timer FFT (message thread only).
- Presets: 17 factory via BinaryData (all synth-only) + user disk under `…/KICKR/`.

**v2 SAMPLE key decisions (AD-11 / AD-12):**
- 6th layer `SamplePlayer` sums with synth **before** TransientShaper → identical downstream chain (drive/tone/stereo/limiter/macros/OS apply). `sampleHP`/`LP`/`Crush` are sample-only, pre-sum, in-region.
- Bank = managed folder `…/KICKR/Samples/`; drag-drop copies files in; presets reference by bare name. **No factory samples.**
- Buffer: in-RAM `SampleBuffer` via `std::atomic<const SampleBuffer*>`; voice grabs the pointer at `noteOn`, holds it for its life; previous buffer retired on message thread once unreferenced. 5 s length cap. Formats WAV/AIFF/FLAC/CAF.
- `SamplePlayer` resamples straight to `fsOversampled` (in-region, no base-rate escape hatch). `sampleMidiTrack` root = C1 (24) in v1.
- Open for Stage 2: interpolation order (Lagrange vs WindowedSinc), per-sample root, `sampleDecay` max semantics.
