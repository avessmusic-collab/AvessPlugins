## Context to Preserve

**Key Decisions (Stage 1):**
- `acceptsMidi() = true`, `producesMidi() = false`, `isMidiEffect() = false`
  - CORRUPTR is an audio effect that also consumes MIDI for control
    (Performance Triggers, Mod Matrix MIDI CC source, optional XY Pad MIDI)
    per architecture.md's MIDI Routing section, not an instrument - stereo
    in/out `BusesProperties` unchanged, no `IS_SYNTH` flag.
- `juce::juce_dsp` module linked from Stage 1 (not deferred to Stage 2) since
  nearly every architecture.md component depends on it
  (WaveShaper/Oscillator/DelayLine/StateVariableTPTFilter/Oversampling/
  Limiter/BallisticsFilter).
- Editor placeholder sized 1200x800 (matches the finalized v5 mockup's
  visible-viewport size) rather than the generic 600x400 default, so Stage 3
  GUI's window-size expectations are already correct.
- All 38 v2 architecture-required parameters (not yet mockup-bound)
  implemented now as real APVTS parameters per parameter-spec.md's explicit
  instruction - Stage 2 DSP and future automation work are not blocked
  waiting on a mockup iteration.

**Prior decisions carried from Stage 0 (unchanged, see architecture.md/plan.md):**
- Distortion Engine implements ONE selectable algorithm at a time (12
  choices), not 12 parallel stages.
- Sequencer pattern data (16-32 steps x 10 lanes) is custom ValueTree state,
  NOT individual APVTS parameters - deliberately excluded from the 94.
- Mod Matrix's 8 slots ARE APVTS parameters (32 total: source/destination/
  amount/enable x8) - bounded scale, host automation expected.
- Master Mix (0-200%, >100% overdrive behavior) will be implemented as a
  custom two-gain crossfade, NOT `juce::dsp::DryWetMixer`, in Stage 2.
- Feedback Routing Path is the single highest-risk, safety-critical
  component - must be built and validated in isolation FIRST (Phase 3.1)
  before anything else depends on it.
- Unified modulation accumulator (Sequencer + Mod Matrix + Macro +
  Performance Trigger, all combining into one per-parameter value) is the
  core architectural pattern tying together 4 of the 14 components - must
  be built and tested in isolation (Phase 3.2) before wiring into real DSP.
