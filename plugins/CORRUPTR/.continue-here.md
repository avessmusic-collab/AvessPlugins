## Context to Preserve

**Key Decisions:**
- Distortion Engine implements ONE selectable algorithm at a time (12 choices), not 12 parallel stages
- Sequencer pattern data (16-32 steps x 10 lanes) is custom ValueTree state, NOT individual APVTS parameters (parameter-list bloat)
- Mod Matrix's 8 slots ARE APVTS parameters (bounded scale, host automation expected)
- Master Mix (0-200%, >100% overdrive behavior) implemented as custom two-gain crossfade, NOT juce::dsp::DryWetMixer
- Feedback Routing Path is the single highest-risk, safety-critical component — must be built and validated in isolation FIRST (Phase 3.1) before anything else depends on it
- Unified modulation accumulator (Sequencer + Mod Matrix + Macro + Performance Trigger, all combining into one per-parameter value) is the core architectural pattern tying together 4 of the 14 components — must be built and tested in isolation (Phase 3.2) before wiring into real DSP
