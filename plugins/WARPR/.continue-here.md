**Key Decisions / deviations recorded in D1:**
- `WarprSynth` is NOT a `juce::Synthesiser` subclass (the base class takes an internal CriticalSection; its voice bookkeeping is bypassed by Poly/Mono/Legato + ghost slots). Block splitting at MIDI timestamps and raw-byte MIDI parsing are implemented in `WarprSynth::renderBlock`. `WarprSound` is not a separate class (voices hold the `SampleData` reference directly).
- Voices own an explicit `SampleData` reference and hand it to the `RetireList` when they end (backlog of 128 if the list is full).
- Mip blend: lower level fully weighted only up to rho = 1; full upper level from half an octave on (`w = min(1, 2*frac(log2 rho))`).
- Sinc8 is an INTERPOLATING Kaiser sinc (beta 5, cutoff Nyquist) so integer positions are bit-exact; band-limiting is the mip pyramid's job.
- Seam crossfade law is correlation-weighted and is skipped for the full periodic single-cycle wave or a "clean" seam.
- Mono (non-legato) retrigger keeps the voice and re-attacks the envelope from the current level; One-Shot loop mode restarts through a ghost fade.
- Unison pan law is a stereo BALANCE law; unison gain is 1/sqrt(N) with no extra compensation.
- Decimator design: `designIIRLowpassHalfBandPolyphaseAllpassMethod(0.10, -105 dB)` for every stage.
- Velocity law 0.25 + 0.75 v (A2); mod wheel stored, no destination.
- State: the sample blob stays empty until D9. `playMode` stays Classic-only (Granular is D7).

**Key Decisions / deviations recorded in D2:**
- Mode names 0-14 are the SPEC's (3 Bend Asymmetric, 7 PWM, 8 Flip, 9 Mirror, 10 Wave Skew, ...), not the task brief's guess (3 PD, 14 Flip). Families: H {0,1,2,3,7,9,14}, V {4,5,6,11,12,13}, VT {8,10}.
- ADAA is applied to the nonlinear REMAINDER (y = x + ADAA(f - x), G = F1 - x^2/2), like the MasterStage knee: plain ADAA of the identity part is a two-sample average, which would make a tiny warpAmount audibly different from a bypass. First sample after a reset uses the naive f(x). Fallback below |dx| 1e-5 is the 3-point Simpson mean, not the midpoint.
- Exact-identity guarantees: every kernel returns the unwarped value bit-exactly at warpAmount <= 0 (phase: Delta == 0.0 exactly -> the plain read; amp: Identity coefficients / gain 1.0); a not-yet-implemented mode is wet = dry; warpMix >= 1 returns wet untouched, warpMix 0 returns dry + 0*(wet-dry). warpEnable off (mix*enable == 0 for the whole chunk) skips the stage entirely (the D1 path); the cycle clock theta still advances.
- BLEP is NOT implemented in D2. Flip and Wave Skew edges are smoothstep ramps of width max(0.1 B, 2 OS samples) cycles (Flip) / 2 OS samples (Wave Skew wrap) - analytic band-limiting by construction since theta is known; PWM corners are C1 quadratic with half-width >= 1 OS sample. True polyBLEP arrives with the D6 BLEP machinery (Hard Sync, ModOsc). Flip at a = 1 is a pure polarity inversion (the window saturates smoothly).
- SeamBridge (Mirror only, `seamJump` flag): at a cycle wrap the stage reads where continuity of the read position would have led and splits the output difference over max(2, os/4) samples. Mirror is therefore not step-free; its T1 bound is the full-swing bound like the other flagged modes.
- Mode-switch crossfade: outgoing kernel keeps the parameters and ADAA history it had at the switch; incoming starts reset; linear weight over 10 ms (`fadeLen` in OS samples). A second switch inside a running fade drops the older outgoing kernel (a step is possible; documented limitation).
- Phase-mode mip selection still uses the UNWARPED rho (architecture's rho_eff is D6 scope per plan); strongly sped-up reads (Bend e up to 5.5, PWM up to 20x) can alias; OS is the mitigation.
- Per-mode constants are documented at the top of PhaseWarp.h / AmpWarp.h. Variable Duty Cycle B maps 0..1 -> duty offset -0.25..+0.25 scaled by a (so the contract default B = 0 shifts the breakpoint by -0.25 a); Wave Stretch/Compress/Expand A = knee blend k = 0.2 + 0.8 A.
- Viz: pushed at ~30 Hz (architecture: ~33 ms; the editor timer is 30 Hz) - the task text said ~60 Hz, the architecture contract wins. Frames are suppressed when entirely zero and the previous pushed frame was also zero, so an idle session emits nothing (the first all-zero frame after prepare is pushed). `voices[]` come from the synth's wait-free playhead snapshot; the editor's G1 merge path only kicks in when a frame carries no voices, so no editor change was needed.

**Key Decisions / deviations recorded in D3:**
- Wrapper: `y = x + g (s(x) - x)`, `s = nrm (N(Dx + b) - N(b))`, `D = 1 + a (1 + 15 A)`, `g = min(1, 20 a)` (rectifiers `g = a`); `a = 0` returns the input bit-exactly (the stage skips the kernel build). ADAA is the D2 remainder form (`ampwarp::runRemainder`). Per-mode constants are documented at the top of `ShapeWarp.h`.
- Spec deviations (structure kept, constants are tuning): 19 Soft Fold / 20 Hard Fold B (outer-fold damping / wall hardness) are a closed-form blend toward tanh; 29 Tube sag is the static `n - 0.3B n^3`; 37 Chebyshev Harmonic keeps the fundamental (`y = u + sum h_n T_n(clamp u)`), no drive; 16 Multi Fold stages are triangle folds with halving thresholds, output x `2^((K-1)/2)`; 34 Exponential clamps u to +-1 (the raw expander overflows); 43 Quantization step edges are a tanh-rounded blend (`kappa = 0.1 + 80 (1 - A)^2`, closed-form F1 via ln cosh).
- Bitcrush IS ADAA'd on its staircase (architecture) but carries `aliasByDesign` with SR Reduction (task/plan: quantisation aliasing is the effect). SR Reduction is a plain hold counted at the OS rate (no ADAA possible). Chebyshev Fold (24) uses the Simpson-numerical ADAA (`adaa::processNumerical`).
- Determinism: dither / jitter use a per-channel xorshift32 reset at note start; L and R share the seed (identical channels stay bit-identical).
- minOS: Hard Clip and Linear Fold are PRE-EMPTIVELY 4 (predicted R1(b); everything else keeps the architecture hints). The A2 test derives the requirement from measurements and fails if a hint is lower than needed; it never lowers a hint.
- Alias-gate operating point: 3.007 kHz sine (exact FFT bin, aliases do not coincide with harmonics), drive 16 (`a = 1`, `A = 14/15`), amplitude 0.25 (u-peak 4); a full-scale (amplitude 1) line is printed for the record. Amplitude 1 at drive 16 is a 16x overdrive whose bandwidth exceeds 2x by construction, so it cannot be a pass/fail gate for the folds.

**D3 risks / what to look at first if a test fails:**
- A1 (>= 12 dB at 1x) is the likeliest failure: first-order ADAA is a one-sample box filter, so the achievable improvement for a harmonic series that is densest just above Nyquist is roughly 6-11 dB by analysis. The measured numbers decide; R1(a) ADAA2 is the documented follow-up.
- Property-test tolerances (5e-6 two-step agreement, 8.3 % exclusion budget, 4e-6 + jump*panel quadrature tolerance), the T1 smooth-input bound `2 sup|s'| x natural step + 0.01` (cap 2.5), the 0.1 / 0.3 FS switch bounds and the Bitcrush / SR alias floor (-55 dB) are analytical estimates.
